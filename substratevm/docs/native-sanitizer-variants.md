# Elide Native-Library Sanitizer Variants

The Elide release pipeline builds Linux amd64 native-library add-ons for AddressSanitizer (ASan), ThreadSanitizer (TSan), and MemorySanitizer (MSan).
Each add-on uses the matching sanitizer variant of the pinned [Elide toolchain](https://github.com/elide-dev/toolchain).
You can also run the "Elide sanitizer native libraries" workflow independently to build artifacts without publishing them.

## Contents

The release publishes _graalvm-natives-<version>-linux-amd64-sanitizer-<sanitizer>.tar.xz_ and its SHA-256 checksum alongside the GraalVM distributions under _dist/_ in the release repository.
The archive contains:

- _lib/svm/clibraries/linux-amd64/glibc/_ with instrumented `libjvm.a`, `libsvm_container.a`, `liblibchelper.a`, and `libzstd.a`, plus native headers and symbol metadata.
- _jars/truffle-api.jar_, _jars/truffle-nfi-libffi.jar_, and _jars/python-resources.jar_ with instrumented Linux amd64 native resources and their regenerated resource metadata.
- _manifest.json_ recording the release, sanitizer, toolchain add-on metadata, native resource counts, and file checksums.

The static Native Image support libraries contain both machine code and ThinLTO bitcode.
Both representations are instrumented.
The replacement jars retain their Java classes and resources, so you can use them in place of the matching release's ordinary jars.
Do not place both versions of the same jar on your class path or module path.

## Use the Libraries

Use the same GraalVM release and Elide toolchain version as the add-on.
Select the corresponding toolchain sanitizer environment before compiling and linking your native embedding executable:

```shell
eval "$(elide-toolchain env --target x86_64-unknown-linux-gnu --sanitizer asan)"
```

You can copy the add-on's _lib/svm/clibraries/_ tree into a dedicated copy of the matching GraalVM JDK, or pass the archives directly to your embedding build.
Link the sanitizer runtime through the matching compiler wrapper.
For ThinLTO, use `-flto=thin -ffat-lto-objects` with the pinned toolchain's linker.
The toolchain's instrumented dependency add-on must also be installed, including for MSan.

When loading ASan-instrumented Java Native Interface (JNI) libraries in an ordinary Java Virtual Machine (JVM), use the toolchain's shared runtime and configure the JVM's signal-handler interaction:

```shell
export LD_PRELOAD="$ELIDE_SANITIZER_RUNTIME"
export ASAN_OPTIONS=detect_leaks=0:handle_segv=0:allow_user_segv_handler=1
```

For TSan in a JVM, the toolchain documents `TSAN_OPTIONS=ignore_noninstrumented_modules=1`.
MSan requires instrumentation throughout the exercised native code; these add-ons do not make an ordinary JVM or generated Java code fully instrumented.
The add-ons cover the listed C/C++ support libraries and native resources.
They do not provide sanitizer instrumentation for Java machine code generated by Native Image, the JDK's native libraries, or the separate native garbage collector libraries from `labs-openjdk`.

## Build and Validation

Run the build from a workspace containing matching _graal/_ and _graalpython/_ checkouts:

```shell
export MX=/path/to/mx/mx
export JAVA_HOME=/path/to/labsjdk
export ELIDE_TOOLCHAIN_HOME=/path/to/elide-toolchain
./graal/ci/elide/build-sanitizer-natives.sh 25.5.5-elide.25 asan "$PWD/sanitizer-out"
```

Each sanitizer uses separate build output and CMake caches.
The build inspects the packaged native libraries for sanitizer references, checks the shared libraries against the release's glibc 2.35 floor, and checks every Native Image archive object for machine code and ThinLTO bitcode.
A native probe links the packaged `liblibchelper.a` and `libzstd.a` with and without ThinLTO, runs a clean workload, and requires a known sanitizer error to be reported.
The ASan job also exercises the packaged Truffle, Native Function Interface (NFI), and GraalPy resources in a JVM, using native Portable Operating System Interface (POSIX), compression, ctypes/libffi, and SQLite support.
The release workflow requires all three sanitizer jobs to succeed before publication.
